# ACM template provenance

`../acmart.cls` is the unmodified class generated by LaTeX docstrip from the official maintainer's v2.20 tag (2026-08-16):
https://github.com/borisveytsman/acmart/tree/v2.20

- Source: https://raw.githubusercontent.com/borisveytsman/acmart/v2.20/acmart.dtx
- Installer: https://raw.githubusercontent.com/borisveytsman/acmart/v2.20/acmart.ins
- Bibliography style: https://raw.githubusercontent.com/borisveytsman/acmart/v2.20/ACM-Reference-Format.bst
- ACM template page: https://www.acm.org/publications/proceedings-template

The template retains its upstream notices and LPPL licensing. The report uses the `sigconf,nonacm` class options for an ACM-formatted course report, with no invented ACM publication identifiers.
